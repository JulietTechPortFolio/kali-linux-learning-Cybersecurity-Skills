Practical 1: Basic Linux commands
My first practice session. Nothing fancy, just getting comfortable in the terminal.
1. whoami
Shows which user I'm logged in as.
bash
whoami
Output on my machine:
kali
2. pwd
Prints the directory I'm currently in.
bash
pwd
On a fresh Kali install I'd expect /home/kali. I'll paste in my actual output once I've run it.
3. ls -la
Lists everything in the current directory, including hidden files, along with permissions, owners and sizes. The -l gives the detailed view and -a includes the hidden stuff (the files starting with a dot).
bash
ls -la
I'll write down what I see in my home folder after I try it.
4. cd /tmp
Moves me into the /tmp directory.
bash
cd /tmp
5. clear
Wipes the terminal screen so it's not so cluttered. (Ctrl+L does the same thing.)
bash
clear
